This project focuses on comparing and aligning two DNA or protein sequences using the Needleman–Wunsch algorithm. The user gives two biological sequences as input, and the system compares them from beginning to end to find the best possible alignment. It considers matches, mismatches, and gaps, creates a scoring matrix using dynamic programming, and then finds the optimal alignment. The project helps identify similarities, differences, and conserved regions between the sequences and displays the final alignment along with its score. This project demonstrates the use of DSA concepts such as dynamic programming, 2D matrices, and traceback in a real-world bioinformatics application.
